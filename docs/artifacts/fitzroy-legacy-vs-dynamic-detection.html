Reading the HY2016 outlier: legacy assigns HY2016's peak to 2015-03 (its wet season crosses the calendar year boundary), while the dynamic detector assigns HY2016's peak to 2016-03 — the same calendar month, one year-label apart. Trough dates agree exactly (2016-11 both). This looks like a year-labelling convention difference between the two detectors, not a true 12-month disagreement — worth confirming before treating it as a timing error in the median-shift gate.
