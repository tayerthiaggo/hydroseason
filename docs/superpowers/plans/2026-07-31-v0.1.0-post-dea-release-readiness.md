**Goal:** Finish the first public HydroSeason `0.1.0` release after the DEA merge with two reproducible studies, complete DEA/cache documentation, release-blocking CI, and a human-gated TestPyPI/PyPI/Zenodo path.

**Architecture:** Consume the green reconciliation baseline from `2026-07-31-dea-merge-reconciliation.md`.
