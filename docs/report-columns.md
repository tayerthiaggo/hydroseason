# Report Export Column Dictionary

This reference documents all CSV export columns generated by `generate_catchment_report` and the underlying export helpers (`build_monthly_export`, `build_hydro_years_export`, `build_events_export`, `build_summary_export`).

## 1. Monthly Timeline Export (`<stem>_monthly.csv`)

| Column Name | Type | Units | Nullable | Route Applicability | Description |
|---|---|---|---|---|---|
| `date` | `string` (YYYY-MM-DD) | Date | No | All | First day of the calendar month. |
| `extent_pct` | `float` | % | No | All | Catchment surface water extent percentage. |
| `invalid_pct` | `float` | % | Yes | All | Percentage of catchment area masked as invalid (cloud/shadow). |
| `observed_fraction` | `float` | Fraction (0-1) | No | All | Fraction of catchment area with valid clear observations (`1.0 - invalid_pct/100`). |
| `quality_state` | `string` | Categorical | No | All | Quality state (`usable`, `low`, `missing`, `unknown`). |
| `candidate_usable` | `boolean` | Flag | No | All | `True` if month passes invalid percentage threshold screening. |
| `smooth_extent_pct` | `float` | % | Yes | `per_year_detection` | Robust smoothed water extent series used for boundary detection. |
| `raw_phase` | `string` | Categorical | Yes | `per_year_detection` | Rule-based monthly phase label (`recharge`, `peak`, `receding`, `trough`, `dry_spell`). |
| `phase` | `string` | Categorical | Yes | `per_year_detection` | Climatologically aligned monthly phase label. |
| `phase_code` | `integer` | Code (0-4) | Yes | `per_year_detection` | Numeric encoding of phase (`0`=dry, `1`=recharge, `2`=peak, `3`=receding, `4`=trough). |
| `hy_year` | `integer` | Year (YYYY) | Yes | `per_year_detection` | Hydrological year assignment (e.g. `2020` for HY 2020-2021). |
| `hy_phase` | `string` | Categorical | Yes | `per_year_detection` | Hydro-year specific phase label. |
| `in_event` | `boolean` | Flag | No | All | `True` if month falls within an inundation water event. |
| `event_id` | `integer` | ID | Yes | All | Unique identifier of the inundation event (1-indexed). |
| `event_peak_flag` | `boolean` | Flag | Yes | All | `True` if month is the peak extent month of an event. |
| `in_low_spell` | `boolean` | Flag | No | All | `True` if month falls within a low-water spell. |
| `low_spell_id` | `integer` | ID | Yes | All | Unique identifier of the low-water spell (1-indexed). |

## 2. Hydrological Years Export (`<stem>_hydro_years.csv`)

> **Note:** Only populated when catchment route is `per_year_detection`. For `event_characterisation` route, this file contains 0 rows (header only).

| Column Name | Type | Units | Nullable | Description |
|---|---|---|---|---|
| `catchment` | `string` | Name | No | Catchment identifier. |
| `hy_year` | `integer` | Year | No | Hydrological year start year. |
| `hy_start` | `string` (YYYY-MM-DD) | Date | No | Start date of hydrological year (trough month). |
| `hy_end` | `string` (YYYY-MM-DD) | Date | No | End date of hydrological year (trough month of following year). |
| `peak_month` | `string` (YYYY-MM-DD) | Date | No | Month of maximum water extent within the hydrological year. |
| `trough_month` | `string` (YYYY-MM-DD) | Date | No | Month of minimum water extent anchoring the year. |
| `peak_extent_pct` | `float` | % | No | Maximum surface water extent percentage reached. |
| `trough_extent_pct` | `float` | % | No | Minimum surface water extent percentage at trough. |
| `amplitude_extent_pct` | `float` | % | No | Extent range within year (`peak_extent_pct - trough_extent_pct`). |
| `recharge_months` | `integer` | Months | No | Duration from trough to peak month. |
| `receding_months` | `integer` | Months | No | Duration from peak to subsequent trough month. |
| `recharge_rate_pct_per_month` | `float` | %/month | No | Rate of water extent increase during recharge phase. |
| `receding_rate_pct_per_month` | `float` | %/month | No | Rate of water extent decrease during receding phase. |
| `boundary_status` | `string` | Status | No | Extrema boundary quality status (`exact`, `interpolated`, `boundary_constrained`). |
| `selection_status` | `string` | Status | No | Boundary selection confidence status (`high_confidence`, `multi_candidate`). |

## 3. Water Events Export (`<stem>_events.csv`)

| Column Name | Type | Units | Nullable | Description |
|---|---|---|---|---|
| `event_id` | `integer` | ID | No | Event identifier (1..N). |
| `start_date` | `string` (YYYY-MM-DD) | Date | No | Start month of water event (extent exceeds event threshold). |
| `end_date` | `string` (YYYY-MM-DD) | Date | No | End month of water event. |
| `duration_months` | `integer` | Months | No | Event duration in calendar months. |
| `peak_date` | `string` (YYYY-MM-DD) | Date | No | Date of maximum extent during event. |
| `peak_extent_pct` | `float` | % | No | Peak surface water extent percentage during event. |
| `total_inundation_extent_months` | `float` | % · months | No | Integrated water extent area under curve during event. |

## 4. Low-Water Spells Export (`<stem>_low_spells.csv`)

| Column Name | Type | Units | Nullable | Description |
|---|---|---|---|---|
| `low_spell_id` | `integer` | ID | No | Low spell identifier (1..N). |
| `start_date` | `string` (YYYY-MM-DD) | Date | No | Start month of low-water spell (extent drops below low threshold). |
| `end_date` | `string` (YYYY-MM-DD) | Date | No | End month of low-water spell. |
| `duration_months` | `integer` | Months | No | Duration of low-water spell in calendar months. |
| `min_extent_pct` | `float` | % | No | Minimum extent percentage recorded during low spell. |

## 5. Summary Export (`<stem>_summary.csv`)

| Column Name | Type | Units | Nullable | Description |
|---|---|---|---|---|
| `key` | `string` | Slug | No | Machine-readable catchment key. |
| `name` | `string` | Name | No | Human-readable catchment display name. |
| `regime` | `string` | Regime | No | Detected regime (`seasonal` vs `aseasonal`). |
| `route` | `string` | Route | No | Analysis route (`per_year_detection` vs `event_characterisation`). |
| `route_reason` | `string` | Description | No | Detailed justification for routing decision. |
| `n_months` | `integer` | Months | No | Total months analyzed in record. |
| `n_hydro_years` | `integer` | Count | No | Total complete hydrological years detected. |
| `n_events` | `integer` | Count | No | Total discrete inundation events identified. |
| `longest_low_spell_months` | `integer` | Months | No | Maximum consecutive low-water spell duration. |
| `amplitude_snr` | `float` | Ratio | No | Seasonal amplitude signal-to-noise ratio. |
| `climatological_peak_month` | `integer` | Month (1-12) | Yes | Long-term median peak month (null if aseasonal). |
| `climatological_trough_month` | `integer` | Month (1-12) | Yes | Long-term median trough month (null if aseasonal). |
| `verdict` | `string` | Text | No | One-sentence summary verdict synthesizing regime and findings. |
