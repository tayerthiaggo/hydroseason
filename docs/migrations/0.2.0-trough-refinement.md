# Migrating to 0.2.0: Trough Refinement Consolidation

HydroSeason 0.2.0 freezes direct-profile refinement as the sole, authoritative algorithm for annual trough-boundary refinement and completely removes the experimental `shape_fit` candidate selector.

---

## 1. Removal of `shape_fit` Candidate

### Background
Earlier development iterations explored two candidate trough refinement policies behind an opt-in `trough_refinement_policy` parameter:
1. `shape_fit`: Parametric waveform template matching.
2. `direct_profile_combined`: Non-parametric robust profile-loss boundary placement.

Multi-scale synthetic benchmarking and real-catchment validation demonstrated that parametric shape fitting struggled on flat-bottomed dryland regimes and asymmetric recessions. Consequently, `shape_fit` and runtime policy selection have been **permanently removed**.

### Removal of Policy Arguments
The runtime parameter `trough_refinement_policy` is no longer supported in public entry points. Any user code passing `trough_refinement_policy="direct_profile_combined"` or `trough_refinement_policy="shape_fit"` should remove this argument.

```python
# Before (0.1.x / experimental):
# result = run_hydroseason(..., trough_refinement_policy="direct_profile_combined")

# In 0.2.0:
result = run_hydroseason(...)
```

---

## 2. Frozen Direct-Profile Refinement Specification

Under the sole runtime method `hydroseason-v0.2.0`, Pass 2 trough boundary refinement uses `direct_profile_combined_v1`:

- **Loss Function**: Weighted Huber loss with transition constant $k = 1.345$.
- **Reference-Level Grid**: Evaluated across candidate low states within $\pm 2$ noise scales of a preliminary valley estimate at $0.25$-scale increments.
- **Combined Scale**: Maximum of robust residual scatter, robust second-difference scatter where available, median single-pixel resolution, and declared tolerance floor.
- **Relative Margin**: $\delta_{\mathrm{rel}} = 0.05$. Candidate low-state months maintaining profile Huber loss within 5% of the minimum loss define the supported low-state plateau.
- **Robust-Loss Support Interval**: The reported support interval reflects the span of candidate boundary locations maintaining profile loss within the relative margin. It is a **robust-loss support interval**, not a nominal confidence interval or Gaussian credible interval.
- **Sensitivity Assessment**: Perturbs uncertain observations across dry-bound, wet-bound, and joint missingness scenarios, alongside bracketing peak shifts.
- **Reason-Coded Abstention**: If evaluable sensitivity scenarios fail to overlap within a contiguous 5-month window, refinement abstains with `BoundaryNotSupported`, preserving the robust Pass 1 boundary rather than guessing.
